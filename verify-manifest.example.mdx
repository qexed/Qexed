# 初始化日志

创建默认配置并启动日志系统：

```rust
use qexed_log::config::LogConfig;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    // 日志配置存储在 <config-path>/config/log.toml，先初始化配置根目录
    qexed_config::init_config_path("./config".into())?;

    let config = LogConfig::default();
    println!("log level: {:?}", config.level);

    qexed_log::init().await?;
    println!("log ready");
    Ok(())
}
```

执行成功后日志写入 `./log/qexed.log`，按天切割，保留 30 份压缩备份。
stdout 中的 `log level: Info` 行来自 `LogConfig::default()`，即文档表中各项「默认值」的来源。
