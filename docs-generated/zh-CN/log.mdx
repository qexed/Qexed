## 日志级别

- 类型：`LogLevel`
- 配置键：`level`
- 可写：是

日志级别，默认 Info，可选：追踪/调试/信息/警告/错误/关闭

- 默认值：`"Info"`

| 值 | 显示名 |
| --- | --- |
| `Trace` | 追踪 |
| `Debug` | 调试 |
| `Info` | 信息 |
| `Warn` | 警告 |
| `Error` | 错误 |
| `Off` | 关闭 |

> 校验失败提示：日志级别只支持 Trace/Debug/Info/Warn/Error/Off
