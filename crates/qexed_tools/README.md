# Qexed Tools

Qexed 的命令行工具集合。GUI 页面工具已移除。

## 可执行文件

- `qexed_favicon_cli`
  - PNG 转 Qexed `server.favicon`
- `qexed_code_of_conduct_cli`
  - 编辑 `enable-code-of-conduct/<语言>.txt`，并切换 `[server].code_of_conduct`
- `qexed_plugin_manager_cli`
  - 管理 `plugins` 目录下的 `.wasm` 插件
- `qexed_installer_cli`
  - 创建和解压轻量安装包 `.qxpack`
